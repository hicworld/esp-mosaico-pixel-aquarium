# Pixel Koi 独立固件

开机后，晴天鱼塘铺满 480×480 屏幕。左划或右划切换晴天与雨天。上划提高音量，下划降低音量，每次调整 10 格，降到 0 即静音。轻点池塘会在指尖附近撒下 3～6 颗鱼食，每次随机。鱼群共有 8 条，部分鱼会游到画面外，投食后也会往池塘里游。

每颗鱼食由最先碰到它的鱼吃。每次进食随机持续 0.50～1.35 秒，吃完继续寻找剩下的鱼食。鱼食吃完后，鱼回到各自的巡游路线。每条鱼的游速不同，游一会儿会放慢，短暂停歇后再出发。

- 晴天有青绿池底、水面树影和移动的波光，播放 `pond_sunny.mp3`。
- 雨天使用较冷的水色。雨滴落到水面后，原地出现扩散和消退的涟漪，播放 `pond_rain.mp3`。
- 两段录音使用完整时长，转成 24 kHz 单声道 MP3 并内置于固件。进入场景从相应录音开头播放，播放完循环。

## 本机重建与安装

这是 ESP-Mosaico 的 ESP32-S31 固件。仓库包含当前版本使用的 BSP、修改版显示适配器和两段环境音。构建环境见[项目 README](../../README.md)，替换环境音的方法见[音频说明](main/assets/来源.md)。在 ESP-IDF 6.1 PowerShell 中进入上级 `animation` 目录运行，首次构建会联网获取其余组件依赖。

```powershell
.\native-pond\build.ps1 -BuildRoot 'C:\esp\koi-pond-build'
python .\native-pond\install.py --platform-image 'C:\esp\backups\my-platform-0.5.3.bin'
```

也可从普通 PowerShell 通过 `-EspEnvironment 'C:\path\to\esp-idf-profile.ps1'` 激活环境。只准备源码缓存时可使用 `-StageOnly`，该操作只需要 Python。开发者仍可通过 `-Platform` 和 `-Adapter` 显式使用其他兼容的平台 BSP 或适配器。

上面的 `install.py` 针对当前已验证的双 OTA 布局。升级时先回到原应用平台，再备份和校验已有镜像，写入 `ota_1` 后切换启动分区。原来的 0.5.3 应用平台在 `ota_0`。在独立固件的 USB 串口控制台输入 `restore`，设备重启回原应用平台。Release 分享包中的独立烧录工具将鱼塘写入 `ota_0`，其恢复方式见分享包说明。

`status` 查看场景和启动分区，`audio_status` 查看正在播放的录音和输出计数，`pond_fps` 查看屏幕实际完成的刷新批次。可用 `scene sunny`、`scene rain` 走同一个场景切换逻辑。
