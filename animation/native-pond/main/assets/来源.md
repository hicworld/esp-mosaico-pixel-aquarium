# 环境音频

固件构建需要 `pond_sunny.mp3` 和 `pond_rain.mp3`，分别用于晴天和雨天。请使用自己有权使用的录音。固件会完整内嵌这两个文件，并在各自场景中循环播放。

用 FFmpeg 转成单声道 24 kHz、32 kbps 恒定码率 MP3，去掉封面和元数据。以下命令在本目录执行。

```powershell
ffmpeg -i sunny-source.wav -map 0:a:0 -map_metadata -1 -ac 1 -ar 24000 -c:a libmp3lame -b:a 32k -write_xing 0 -id3v2_version 0 pond_sunny.mp3
ffmpeg -i rain-source.wav -map 0:a:0 -map_metadata -1 -ac 1 -ar 24000 -c:a libmp3lame -b:a 32k -write_xing 0 -id3v2_version 0 pond_rain.mp3
```
