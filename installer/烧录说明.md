# Pixel Koi 1.3.0 固件

适用硬件为 ESP-Mosaico / ESP32-S31，原装 480×480 触摸屏与 16 MB 内部 Flash。该包提供完整启动所需的 bootloader、分区表、初始 OTA 数据和鱼塘应用。

这是开机直接进入鱼塘的独立固件。默认烧录会覆盖 ota_0 中原来的应用平台，并重设 OTA 启动选择。烧录后，鱼塘的 restore 命令无法恢复此前的平台。需要保留原平台的用户应先准备自己的备份与恢复方案。

脚本只写入下表所列区域，保留 NVS、外部 NAND 和表中未列出的区域。程序启动后可以保存自己的设置。该分享包的独立安装方式与源码中专用于保留 0.5.3 平台的安装器采用不同的启动槽。

## Windows 使用步骤

1. 安装 64 位 Python 3.11，并勾选 Add Python to PATH。
2. 完整解压分享包，使用 USB 数据线连接 ESP-Mosaico。关闭占用串口的监视器和其他工具。
3. 双击“烧录固件.cmd”。首次运行会在本文件夹创建 .venv-flash，并联网安装 esptool 5.3.1 与 pyserial 3.5。安装失败后可直接重试。
4. 按显示的列表输入 COM 端口。运行端口与 ROM 下载端口可能不同，以当前设备为准。
5. 核对覆盖范围，输入 INSTALL 开始。脚本先校验固件摘要与目标格式，再请求进入下载模式，要求 esptool 识别 ESP32-S31 后写入。
6. 等待写入后的 Hash of data verified 提示和设备重启。开机显示晴天鱼塘。

自动进入下载模式失败时，可按住 BOOT，点一下 RESET，再松开 BOOT，重新运行并选择新出现的 ROM 端口。若当前固件不支持 download 命令，请手动进入下载模式后重试。烧录期间保持 USB 连接与供电。

出现报错时，窗口会保留输出。可检查 USB 数据线、COM 端口与串口占用，按报错修正后重新运行。

## 只检查文件

在当前目录打开 PowerShell 并运行以下命令，只校验文件，不打开串口。

    python flash_firmware.py --check

该检查使用 Python 标准库，核对四个文件的 SHA-256、应用名 pixel_koi_pond、版本 1.3.0、ESP32-S31 芯片标识、分区和启动槽。完整 SHA-256 清单位于 SHA256SUMS.json。

## 默认写入

| 地址 | 文件 |
| --- | --- |
| 0x2000 | bootloader.bin |
| 0x8000 | partition-table.bin |
| 0xf000 | ota_data_initial.bin |
| 0x20000 | pixel-koi-pond-1.3.0.bin |

脚本使用 115200 波特率、ROM 模式、--no-stub、DIO、80 MHz、16 MB Flash。恢复应用平台需要再次烧录对应平台固件。
