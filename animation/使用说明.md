# Pixel Koi 像素鱼缸动画

Pixel Koi 1.3.0 默认播放俯视鱼塘。青绿池心、深色池岸和缓慢明灭的水光参考桌面鱼塘视频。三条锦鲤先后入场，轻点投食后会聚拢，再游回原来的路线。背景音乐使用平台内置的轻柔八音盒曲目，音量沿用设备设置。
## 安装

应用在支持快速定时回调的 Mosaico 固件上按 60 Hz 调度局部刷新，并在游动模拟步之间插值。使用 0.5.2 等旧版固件时，应用按原定时回调运行。

`dist/pixel-fish.app` 是已签名应用包，适用于信任本机开发签名的 **MicroPixel Mini App Platform 0.5.0 或以上**。本机的 ESP-Mosaico 使用支持 60 Hz 的 **0.5.3** 固件，USB 串口为 **COM4**。从系统首页安装这个应用包，系统固件照常使用。

在本目录打开 PowerShell，连上 USB 数据线，并让 ESP-Mosaico 回到首页。用本机已有的工具安装。

```powershell
python "C:\esp\mini-app-platform\tools\install_usb.py" ".\dist\pixel-fish.app" --port COM4
```

串口变动时，把 `COM4` 换成设备管理器中显示的端口。安装后在首页打开 **Pixel Koi**。

## 播放和校准

| 操作 | 效果 |
| --- | --- |
| 打开应用 | 显示池塘并播放音乐，5 秒后三条鱼先后游入 |
| 点左上角音符 | 开关背景音乐，记住选择 |
| 点右上角波纹 | 在池塘和黑底倒影之间切换，记住选择。黑底模式下仍可点右上角切回 |
| 游动时轻点 | 在点按附近投食，鱼游过来，再分开 |
| 同一个位置双击 | 重新开始 5 秒入场倒计时 |
| 长按约 0.6 秒 | 进入 `F↑` 倒影校准 |
| 校准时轻点 | 切换旋转或镜像方向，从盒子正面观察 |
| 校准时再长按 | 保存当前方向并开始新的 5 秒倒计时 |

默认按 **屏幕朝上、USB-C 朝右**的托盘姿势设计。从盒子正面看到 `F` 正向、箭头朝上，方向就校准好了。应用使用显示、触摸、本地存储和可选的扬声器。存储用来记住校准方向、画面模式和音乐开关。

## 放进鱼缸拍摄

先点右上角切到黑底倒影模式。把托盘抽出来，双击后趁 5 秒黑屏把它推回去。固定正面机位，从推入托盘拍到三条鱼陆续出现，中间保持同一镜头。应用画布为黑底，宿主保留首页栏。若栏位反射进画面，可以在托盘上方、靠 Home 栏那条边加一条约 **6 mm 宽的哑黑卡纸**遮光，鱼仍在中央画布内。

`pixel-fish-preview.gif` 来自同一份 WASM 在电脑上渲染的池塘画面。

## 改源码和重建

- `pixel-fish/manifest.json` 定义应用 ID、版本和权限。
- `pixel-fish/main.c` 处理触摸、倒计时、校准和场景提交。
- `pixel-fish/pond_motion.h` 处理游动、转向和投食聚拢。
- `pixel-fish/fish_art.h` 负责合成鱼、鱼食和水面，提交变化区域。
- `make_pond.py` 生成池底贴图，`pixel-fish/water_art.h` 绘制局部水光。
- `pixel-fish/pond_audio.h` 接入平台的音乐并保存开关。
- `make_textures.py` 绘制花纹和鱼鳍，生成 `pixel-fish/koi_poses.bin` 和 `koi_textures.h`。改图后运行 `python .\make_textures.py`，需要 Pillow。
- `verify.mjs` 执行实际 WASM，检查出场、局部刷新、游动、投食、重播、倒影校准和 60 Hz 定时回调。

```powershell
python .\build.py
node .\verify.mjs
```

重建安装包使用本机 MicroPixel 工具链和已有签名。项目 ZIP 内含应用包、WASM、源码、验证脚本与预览。
